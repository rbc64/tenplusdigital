# tenplusdigital.com

The Tenplus Digital website: studio homepage, portfolio and the Lab (free tools).

- `index.html`: homepage
- `portfolio/`: portfolio page; thumbnails live in `portfolio/images/<year>/`, listed in `portfolio/manifest.json`
- **Add new thumbnails:** upload them to [`portfolio/uploads/`](portfolio/uploads); see the README there
- `.github/workflows/site.yml`: converts uploads and publishes the site on every change
- Tools: [unmix.tenplusdigital.com](https://unmix.tenplusdigital.com) · [hush.tenplusdigital.com](https://hush.tenplusdigital.com)
